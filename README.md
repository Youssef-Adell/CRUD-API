# CRUD-API

This is a Simple CRUD API, there are no business logic or any heavy manipulation here because the goal of this project is to apply each new concept i learn in my journey to become a backend developer.


## I learned and applied these concepts/technologies to the project

- Handling different HTTP Requests (Get, Post, Delete, Put, Patch)
- Implementing Paging, Filtering, Sorting, Searching techinques
- Handling Exceptions and returning appropriate Http statues codes to the consumer

- Dependency Injection and DI Containers
- Repository & Unit-of-work design patterns
- Clean Architecture to seperate the core business logic from the infrastructure dependencies

- CORS to restrict API resources to be accessed from another domain
- DTOs to decouble the reques/response represention from the actual entities
- Content negotiation to make the API able to support different formats(JSON, XML)

- ORMs such as EF Core to map our Entities to SQL tables
- DBMS such as SQL Server
- ASP.Net Web API concepts such as: Middlewares, Routing, Model-binding, Filters, validation


## Built With

- C#
- ASP.NET Core Web API Framework
- Entity Framework Core
- SQL Server


## Used Packages

- Nlog: to Log exceptions and errors
- AutoMapper: to map actual entities to Data Transfer Objects and vise versa
